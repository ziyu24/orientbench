# OrientBench

OrientBench 是遥感旋转目标检测方向可靠性与可辨识性的极简研究项目。

研究对象以DOTA系列目标为准，不研究建筑。不得继续以建筑足迹、屋顶或高程作为当前科学终点。
首次适配验证仍按项目规则优先用HRSC2016船舶；正式DOTA问题须在相应类别和标注定义下验证。

- 源码：`src/orientbench/`
- 测试：`src/tests/`
- 配置：`configs/`
- 文档与历史恢复：`doc/`
- B/C讨论、SERVER指令、结果与失败路线：`lab/`

当前活动 SERVER 指令以 `lab/sug.md` 的唯一 `rNNN` 小节为准。继续研究时先更新
`lab/discussion.md`，再用收敛后的单项科学任务替换该单槽。

科研交付默认直接更新任务单和简短Markdown；不制作PDF或额外长报告。
用户要求此前期刊潜力评估全部作废；当前重评与下一科学问题以`lab/discussion.md`为准，
旧文档中的期刊档次结论仅为历史观点，不是当前裁决。实验事实及其适用范围仍保留。
