# SERVER 科学指令

## r017 真实多视角建筑轮廓损失的交叉对照

直接完成冻结数据的获取、实现、两次训练与评估。问题是：同一地物上，互补方向的第二幅
真实影像，相对近方向的第二幅影像，是否降低官方建筑标签上的损失。这是整体视角收益的
探索实验，不是独立PSF机制、因果识别或新选角方法。原生元数据与训练成员清单已实际取得；
无需再派入口核查或等待US3D。首次验证改用SpaceNet4，因为HRSC2016不适配此同目标真实多视角问题。

使用冻结四个WV02视角：A=1030010003472200、B=103001000392F600、
U=10300100036D5200、V=1030010003315300。U对A冗余、对B互补，V对B冗余、对A互补。
只用官方训练分区内已固定的256个训练区域和128个评估区域；评估区域属于16个空间块，
与训练区保留450米地物边界间隔。原生筛查依据相交条带均值，不冒称逐像素标定。

共享FCN-ResNet50单视角建筑分割模型，公开ImageNet初始化骨干、全参数训练。
四视角每个训练区域每轮各用一次；seed1701与1702各30轮，共两次拟合。
固定448输入、RGB原值除3000裁剪后做ImageNet标准化、D4联合增强，AdamW学习率1e-4、
权重衰减1e-4、微批4且累积2，无调度或warmup；使用末轮模型，不按评估结果选模型。
详细冻结参数、数据清单和执行说明已随本任务提供，不临时改样本、模型、训练轮数或预处理。

真实建筑标签按共同地图边界栅格化，四视角用共同有效像素；零字节标签已在选样前排除，
有效空标签保留为负例，黑像素不自动当无效。训练前仅在训练样本核验影像与标签对齐。
两次训练完成前不解码评估像素或标签；不访问官方验证集或测试集。

训练与评估采用固定训练前景比例确定的类别加权二元对数损失，分母是有效像素数，
再按图像平均；不得按批次重算权重或除以权重和。融合取对齐概率算术平均后再计损失，
不能改成平均logit、硬投票或平均单图损失。

唯一主量I=[L(A,U)−L(A,V)+L(B,V)−L(B,U)]/2，正值倾向互补。
同时报告两个参考方向、各seed、四个单视角及四对融合损失、固定阈值前景IoU、
常数0.5基线（训练加权CE的最优常数）和训练前景比例常数基线，以及A/B各自0°与90°两次推理的TTA。
先每切片每seed，再块内等权、两seed等权、16块等权；配对空间块bootstrap两万次，
报告唯一主量95%区间，其他区间仅作描述。切片、空间块和seed不算独立过境。

输入或执行错误、模型不足、收益不确定、科学阴性必须分开。若基线不足、主量不确定、
两个方向或seed矛盾、或互补不能超过对应TTA，则结束本轮且不自动扩展。
即使结果一致为正，也只支持此过境、四视角和固定基准下的现象，不直接宣称机制或期刊创新。
归档实际训练、逐区域/逐块统计、结论和主要失败边界；结束后清空任务槽。
r015及所有原停止路线维持停止，不借此恢复旧训练或追加修复。
