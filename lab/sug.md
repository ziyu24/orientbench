# SERVER 科学指令

## r025：DOTA同图重标差异与完整预测可恢复性核验（已执行）

前一任务已结束，结果及适用边界已归账。本轮承接B/C收敛的同任务比较问题：
固定检测器输出时，模型优劣能否与标注修订带来的评价变化区分开。
本轮是一次完整输入核验与标注差异测量，不是顶刊方法确认；落实必要程序并实际执行，
不能只返回计划。研究飞机与船舶，不研究建筑。

### 固定范围

- 主比较固定DOTA1.0与DOTA2.0公开validation原图及原生四边形标注；已有同名交集458张
  是待核实清单，不是预设成功计数。列出两边独有成员，不为凑458补图或换split。
- 全部同名原图都纳入身份检查，包括飞机/船舶为空的图。不使用切片数量冒充母图数量。
  不读取官方隐藏test，不把不同像素的图混入同图标注比较。
- 检测器资产固定为原ORCNN与RTMDet。先核查历史完整预测及其生成记录，不换模型追可用结果。
- 零训练、零新模型推理、零新种子；不下载大型数据或权重。必要的公开发布说明和既有
  模型目录元数据可以读取。完整预测缺失不能用matched-only记录、旧AP或合成输出补齐。

### 执行内容

1. **核验版本与全部原图。**记录数据发布来源、split身份及原生标签来源证据；目录名字
   不能单独证明官方身份。逐图比较文件内容摘要、解码尺寸与像素；字节不同但解码数组
   完全相同可记为编码差异，像素不同/缺失/无法解码须单列，不能静默删去后声称全体配对。
   不以resize、重投影或近似相似度把不同输入变成同图。给出完整配对清单与异常原件入口。
2. **测量标签差异。**在已确认同像素的图上读取两套完整原生标签，保留原行号、类别、
   difficult和四边形。先检查有限坐标、非零面积、自交及重复；合法顶点循环起点/绕向
   改变不算几何修订，不以最小外接矩形替换原四边形。分别报告字面差异与规范化后的差异。
   解析失败、非法几何或缺失difficult保留为明确异常，不默认为空标注或正常对象。
   重点报告飞机/船舶；为辨别类别改名，可读取同图其他目标的标签字段，不扩展研究对象。
3. **保守地建立对象对应。**先按同一多边形建立唯一对应，坐标容差固定为原图像素1e-6；
   同多边形的类别/difficult变化分别保留，重复标签有歧义时不任意选一个。余下标签以
   原生多边形IoU≥0.5建立跨版本候选边，不预先按类别过滤；仅两端均只有一个候选的边
   暂作几何对应。保留所有候选边、多义组件及无候选对象，不用强制最近邻配对消除歧义。
   同形阶段已发现的重复歧义保持未决，不在后续阶段任意消解。此规则仅是操作性对应，
   不能证明低重叠对象消失或新增，也不能排除密集场景错对应。
4. **分别统计变化类型。**输出几何不变、仅类别/difficult变化、几何修订及共同变化，
   以及旧版独有/新版独有候选和无法对应对象；后两类不能直接叫真实删除/新增。
   对无歧义几何候选报告IoU、质心位移和面积比的完整分布及逐图计数，保留零变化。
   用全体对象计数核对分区守恒，不把无法对应者从分母隐去。不把框轴变化当语义航向真值。
5. **一次性查明完整预测来源。**沿本项目原生成程序、历史清单、正规持久与实际运行产物
   定向查找两模型的完整输出、图像顺序、切片到母图映射、缩放/偏移、合并NMS、置信截断
   及每图最大输出数。先看原件与生成逻辑，再判断是否完整；“每个已匹配对象一行”不合格。
   确认无检测图仍在母图清单中，FP及重复预测没有按GT删除。已存在归档只读检索，不覆盖
   或搬迁唯一证据，不扫描其他项目，不恢复旧控制流程。
6. **核查训练接触与重建条件。**核对两模型实际训练/选优数据与当前母图的交集，不能以
   权重文件名推断train-only。交集不明就报告未知；见过这些图的输出只能支持训练接触条件
   下的描述，不能冒称未见数据上的模型泛化比较。原输出确实找不到时，按现有通用模型
   目录定向查询同两模型的配置、权重来源及训练口径，只给出可核实的重建条件与具体缺项，
   本轮不启动替代推理或训练。记录实际查过哪些范围，避免把有限查找写成全盘不可恢复。

### 交付与结束

- 必须交付完整图像配对、逐对象对应及歧义、标签变化汇总、两模型预测与训练来源清单，
  并保留能复算这些表的程序和参数。图像身份失败也照实交付清单，其余可独立完成的核查继续。
- 对多边形循环移位/反向、重复标签、类别更改、difficult更改、密集多义对应和无对象图做
  必要正确性检查；独立从原生记录复核成员计数及变更分区，不能只复算生产者汇总数字。
- 简短Markdown结论回答：同像素版本比较能覆盖哪些图；飞机/船舶是否有可核实的几何变化；
  对象清单变化与对应歧义各有多少；两模型能否重算完整母图AP；还缺哪项具体输入。
  大型明细保留为运行产物，小型结论及重建所需源码/配置按项目规范提交并推送。
- 本轮不计算新AP、不构造逐对象混合真值、不做显著性/排名筛选。没有几何变化只限制
  这个版本干预入口；资产缺失或对应不明属于输入限制，不否定整个科学问题。
  交付后结束本任务，不自动追加版本、模型、图像或种子。
