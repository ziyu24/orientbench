# SERVER 科学指令

## r020：同两模型、同两次推理下的额外影像价值

目标：位置校正之后，检验真实互补双图是否优于首幅同图双模型；这是固定强替代检验，
不是新选角器或顶刊方法确认。r019已归账，当前只有本任务。

- 固定复用原末轮seed1701和1702两模型、原四视角、256训练区域、128评估区域、16空间块。
  两模型是每次两前向动作的组件，不是新增训练重复；零神经网络训练，不宣称跨seed稳定。
- 第一模型复用r019位移；仅对第二模型新增训练区域1024图前向，用与r019相同中心384、
  类别权重、整数±32范围及并列规则拟合四个位移。保存完整损失面，全部训练区域所选/零位移
  直接损失核对误差≤1e-10，固定落盘之后才打开评估预测/标签。边界最优不扩大范围。
- 复用两模型已验收完整概率；同图动作为两模型对首图的概率均值，双图动作为两模型分别
  看首图和候选图的概率均值。两种模型分配都列出并平均各自损失，不挑更好分配、不混合
  四张预测。每种实际动作均两次前向，同图/双图获取要求不同，不声称总经济成本相等。
- 联合主比较分别是A方向同图损失减AV双图平均分配损失，以及B方向同图损失减BU损失。
  校正中心384、实际缓存标签为主；中心零位移及直接448标签是冻结敏感性。
  同时报告每种分配、AU/BV冗余动作、交叉差、全部动作损失与按块求比再平均的IoU。
- 块内区域等权、16块等权、固定20000次配对空间bootstrap；两个主比较各报97.5%双侧
  区间作Bonferroni近似处理，另报描述性95%区间。已使用评估集不获得新盲确认身份。
- 两侧主区间下界均正才支持两个方向均胜过这个具体替代；一侧跨零报告不确定，
  不改用总体均值或较弱基线宣布全面成功。标签或模型分配冲突完整披露，不挑口径。
- 零下载、零新训练；新增预测最多20亿字节，推理最多1 GPU小时，总墙钟最多3小时。
  不访问官方validation/test，不补模型、seed、epoch、尺寸或校正自由度。一次结束归账，
  不自动追加实验；原已停止的方法族保持停止。
