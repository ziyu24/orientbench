# SERVER 科学指令

## r021 获取前边际收益预测：新产品与新地理区域留出

目标：只用首幅影像的任务预测及候选名义观测方向，学习未来预测与真值的条件联合分布，
检验其能否比直接收益回归更准确预测第二幅影像相对同图等计算动作的收益，并改善实际选择。
这是面向顶刊问题的首次方法筛选，尚无阳性结果，不承诺期刊创新，不恢复已停止的方法族。

固定SpaceNet4 Atlanta官方训练分区，128区域/8产品拟合，64区域/8产品开发校准，
64全新区域/4未参与开发的产品最终留出；8个新地理块与全部旧区域至少450米间隔。
仍是同城、同过境、同传感器，不称独立新过境或跨城市验证。HRSC2016不适配此真实多视角问题。

复用既有末轮模型，首模型1701、第二模型1702固定分工，二者是动作组件，不新增网络训练或随机重复。
每动作含首图恰两前向，比较同图双模型与跨图双模型概率平均。沿用实际预处理、实际加权对数损失、
中心384及900栅格再缩448主标签，直接448仅敏感性。开发位移只在128拟合区估计；
留出位移按名义方向最近的开发产品转移，不用留出标签修正。

执行冻结的16概率箱、5边界上下文、几何核条件联合分布风险积分，与直接收益ridge、纯几何预测、
最大方向间隔、最接近天底、始终停止及保持边缘分布的独立性消融比较。
各预测器仅在开发校准拟合一个加性偏差；开发校准选定一次最强参照，留出不选基线或调参。
条带名义几何只是理想获取计划的回溯代理，不声称已实现真实获取前遥测或经济成本优化。

先冻结方法、偏差、参照和位移，再用留出首模型保存全部候选收益预测与动作，最后才执行
留出第二模型并读标签。每次决策只能接收该首图预测和两几何，不读候选像素、预测、质量或身份。
全部候选实际风险均保留；结果不佳不换成员、加种子、追加模型或扩大超参搜索。

联合主量：冻结最强参照风险减方法策略风险；ridge收益MAE减方法收益MAE。
首图均值到区域再到8个地理块等权，固定20,000次配对块bootstrap、各97.5%区间。
两个下界均大于零才支持此有限留出上的方法价值，其他比较和直接448均描述性。
报告各方法风险、MAE、偏差、获取率、oracle regret、逐区逐块结果及限制。

固定新增1,024张影像、2,048次图像前向；下载上限8GB、新预测4GB、推理2GPU小时、总墙钟8小时。
完整有效支持或预算不满足则保留证据报告执行限制，不伪造科学阴性，不扩范围补样。
完成后将结果及主要失败边界归账，保留充分统计和可复算原件；本轮不自动扩展下一任务。
