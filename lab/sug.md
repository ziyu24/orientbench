# SERVER 科学指令

## r023：三比特可见性对高程歧义的有限上限筛选

目的：在已知几何、固定三图和相同完整候选类下，检验每查询额外三个可见性比特的增量。
这是新的有限合成高程问题，沿用已讨论假设，不恢复r022预测器；HRSC2016不适配此三维问题。

固定3,125个无纹理不透明柱体场景为完整候选类，48评价场景、四组各12、唯一seed1701；
每景4个物方查询，共192查询。三幅正交图同方位、无噪声、已知同色物体，结论只限此合同。

1. 核查全部候选及固定几何分层清单，保留所有评价场景、共同遮挡和零宽查询。
2. 强基线用全部三图约束精确枚举相容场景。oracle仅增加当前查询三个可见性布尔值；
   不给对应点、深度、类别或其他查询比特，不按真值裁剪候选类。
3. 保存完整相容集合和高程上下界，以独立投影/阴影算法复核全部候选，重算全部192查询。
4. 先景内等权再景间等权，S=1-mean(W_oracle)/mean(W_base)。总体S>=25%，
   部分遮挡及深度边界各S>=10%才支持有限信息筛选；分母零报告无空间，不加epsilon。
5. 真值遗漏、空集合与区间扩张必须为零；不满足属于实现/合同问题，不能写科学阴性。

无训练、无下载，单次完成；不改成员、阈值或种子追结果。有效结果回写结果账，主要有效负结果
同时归失败账。阳性只证明特权比特在该有限类的价值；阴性只结束该有限候选，不外推全领域。
