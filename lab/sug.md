# SERVER 科学指令

## r014：RarePlanes 来源身份修正与既有六模型证据重建

### 1. 唯一目标与范围

核实 r013 实际执行是否使用了 CAT-only 错源映射；在原始训练输入与六个模型身份成立时，恢复
同一 calibration 对象的正确来源，复用既有模型重算原 H1a 三臂，并交付 B 可独立复算的证据。

这是 correction-only，不是新的创新实验，也不是重新开展六次拟合。RarePlanes 的独立飞机属性
是原问题的固定终点；单类 HRSC2016 不适配，本轮也不更换数据集。

允许读取既有 train/calibration 的必要像素并做六个冻结分类器的有限前向；禁止任何参数更新、
补训练、新 seed、模型或 checkpoint 选择、数据扩充、detector 推理、H1b/H2、selector/head、
risk/coverage、SAR、HRSC、论文修改及任何 test 像素、crop、前向或性能计算。公开元数据和既有
test 分区登记仅可用于确认边界，不得借此打开 test 影像。本轮不下载新数据或模型。

### 2. 先保全旧证据，不能以新结果替换历史

保留并发布 r013 实际生成/验证代码、原始训练与校准输入记录、六模型身份、执行时序、原始
compact predictions、draws、统计和原始裁决。明确区分当时产生的记录与本轮新增的审计记录；
不能补写旧时点、硬写检查通过，或把另一版本源码当作原执行源码。

用旧原始预测独立重算原六格摘要，报告哪些数字可复现、哪些缺失或不一致。保留旧 canvas，
不得覆盖它们。如果实际曾用未发布的正确实现，必须公开该实现与原产物的对应关系，不能只声称
“本机已修复”。原始证据缺失、无法绑定实际版本或无法恢复固定对象集合时，报告缺口并停止
模型前向；不得制造一份新的自洽记录去追认旧执行。

### 3. 训练输入与模型可复用性

- 按原始 G0 登记确认 253 个 image records、227 CAT、14,707 个 full objects，以及既有
  lexical-PCG64(1010) 的 test/calibration/train 25/25/52 component 集合；逐键核对，不只数行。
  只重建核验既有划分，不改排序、重新随机化、合并/拆分或择优替换分区。
- 实际训练集保持原登记的 4,065 个 eligible objects，不把新 train split 中旧
  Public_Train=0 的 1,302 个 full objects补入。解释5,370→4,068→4,065的来由，并报告
  实际训练集的各属性类别支持。
- 对全部4,065个训练canvas，从原影像及原几何独立重建只读比对，核对对象、来源、像素与原始
  训练登记完全一致；不要覆写缓存。仅存在文件、shape相同或摘要自洽不等于来源正确。
- 仅复用 r013 已完成的 ResNet-50、ViT-B/16 各 seeds 1201/1202/1203 的六个 final-epoch
  模型。逐一验证架构、seed、八epoch完成记录、冻结初始化来源、参数内容与原输入的绑定，
  并严格加载；不得使用r012完整/部分模型替代，不能从后来候选中选六个。
- 参数和所有模型buffer在本轮前后必须相同，全程评估模式且不构建优化更新。训练输入、原模型
  或初始化来源无法核验，或发现实际训练用错数据，立即保持inconclusive；本轮无权修复训练。

### 4. 对象—来源—几何—像素逐键修正

对象ID按冻结GeoJSON顺序解释，同时保存原对象属性及几何身份，不能将顺序ID当作跨版本永久ID。
全部calibration沿用原7,418个full objects与原7,416个共同eligible集合；两者差集的两个对象及
原排除原因必须明确。不得根据当前预测、错源与否、内容或类别删对象。

禁止以CAT单独取图；每个对象须同时满足loc_id、canonical CAT、image_id及G0的source_cog一致。
CAT必须当字符串保留原值，规范恢复沿用既有规则；一键多源、缺源、source_cog矛盾或分区矛盾
必须显式失败，不允许字典后值覆盖、猜图或填零图。

独立核验原标注地理polygon经实际COG的CRS/affine转换后，与冻结pixel center、L/S、long-side
RP1 theta、canvas范围一致；覆盖角度单位、像素中心约定、边长交换与180°周期。重建的正确
canvas必须由第二路径从原COG逐对象读取并与第一路径逐像素比较；离散键、对象集合和uint8
canvas要求零差异。任何超出本次来源修正的几何/训练语义矛盾先报告，不静默重定义估计量。

分别发布“公开旧代码会错源”与“原实际canvas已确认错源”的计数。核对B复算的2,318个full
objects、20个loc–CAT键以及两个component（loc:44,107；loc:51,54,84,86,106,108,113）；
报告精确eligible受影响数，不硬凑该计数。差异必须可逐键解释，否则停止。
不得删除受影响component，也不能把对象行比例当成component-equal风险权重。

### 5. 恢复同一三臂，真实检验render

仅当第2—4节成立后，使用正确来源为同一eligible对象重建clean、theta−10°、theta+10°。
保持GT中心、L/S、raw RGB/255、1.20L×1.20S物理范围、224×224输出、单次bilinear affine、
原像素中心、边界、颜色与反走样约定；不改角剂量、加增强或扩大裁剪支持。

每臂保留theta与theta+180°两视图的类别概率，先等权平均再argmax；二分类平局固定为类别0。
两视图像素本来不必相等，正确检查是RP1等价表示下视图对一致（允许成对交换）及平均概率一致，
不能把恒真布尔值或“两次调用同一个render”当作独立验证。

独立render/reference不得导入生产者的裁剪、坐标或mutation函数。用真实train只读夹具与合成
解析夹具事先固定浮点容差，并在读取修正模型结果前公开；不能依据calibration性能放宽容差。
全部对象核对坐标/范围；真实像素对照至少覆盖全部20个冲突来源键及所有未受影响来源分组，
对象按固定ID顺序选择，不能看预测后挑样本。

检验identity、等价w/h+90°经long-side规范化后的视图对、theta+180°视图换序及非零±10°响应。
对具有方向结构的夹具要求角扰动确有非零响应，不要求每个近常量真实patch都显著变化。
额外注入错source、仅错配对象标签/概率行、度弧度混淆、漏一模型、NaN和零分母样例，验证器
必须实际拒绝；全字段共同重排再按对象键对齐则结果不变。零方差合法退化样例按第6节正确处理。
不得只提交“all_pass”。

六个既有模型只产生同一三臂的修正预测，不再训练。保存每对象、架构、seed、属性、臂、两视图
及平均后的完整二类概率与错误标记；核对有限值、概率范围/归一、标签、行序和共同对象集合。
旧表与修正表分别保存，差异按受影响/未受影响来源描述，不据差异选择模型或修改协议。

### 6. 完整恢复原统计合同，不重新调门

主量仍为2架构×3属性的六个co-primary。属性标签沿用原wing straight、engine count=2、
propulsion=jet为类别1及原其余合法类别为0；未知值不得重映射。

每属性类别先在含该类的component内平均对象错误，再在含该类的component间等权，两类各权1/2，
得到每架构、seed、臂的R。缺某类的component不补零、不进入该类分母。主效应固定为：

Delta[m,k] = mean_seed((R[m,seed,k,+10] + R[m,seed,k,-10])/2 - R[m,seed,k,clean])

在原25个calibration components上，用PCG64(12012)按原随机流产生50,000个有效同步component
bootstrap draws；同一draw用于所有模型、seed、属性、类别和三臂，完整重算分母。零类别分母的
draw按原随机流顺次替换并披露数量，不能固定抽50,000次后忽略无效项。

六格sd使用ddof=1。对sd>0的格，以每draw的max_j(abs((Delta_bj−Delta_j)/sd_j))的type-7
95%分位q构造Delta_j±q×sd_j；零方差格用退化区间，六格全零时q=0。功效保持原诊断定义：
mean_b(0.020 + Delta_bj − Delta_j − q×sd_j > 0)。

用同一draws对六格seed-averaged clean risk另建独立六维同时区间，同样处理零方差。
clean upper须全部<0.5，18个架构×seed×属性head在clean共同总体上均非单一类别。

第二统计实现不得导入生产者的聚合/抽样/裁决函数或信任其布尔值，须从原始概率独立核验：
对象/标签/来源集合、每对象错误、class/component分母、逐seed风险、全部draws与被排除draw、
六格Delta/sd/q/上下界/功效、clean风险及其sd/q/区间、18个clean head和最终裁决。
离散值须完全相同，浮点统计使用float64、绝对容差1e-10且相对容差0；提交实际最大差异。
修复二维Delta裁决、NaN传播和零方差处理，禁止用放宽容差或直接复制主摘要获得一致。

### 7. 裁决与停止

仍按原r013顺序给出一个注明“r014 correction-only重建”的H1a裁决：

1. 证据、输入/模型身份、训练可复用性、信息墙、支持、render或独立统计任一无效：
   INCONCLUSIVE_R013_H1A，并给实际原因；不得落入科学PASS/KILL。
2. clean utility任一失败：INCONCLUSIVE_R013_H1A，reason=TRAINING_UTILITY。
3. 有效且任一格simultaneous upper<0.020：KILL_R013_H1A。
4. 否则任一格功效<0.80：INCONCLUSIVE_R013_H1A，reason=POWER。
5. 否则六格未全部满足Delta≥0.020且simultaneous lower>0：KILL_R013_H1A。
6. 仅剩全部满足时：PASS_R013_H1A。

输入已校验却clean utility失败时，不能改回原错图结果；执行失败与负效应必须分开。
POWER只是冻结合同的诊断，不是基于新结果追加样本/seed的授权。任何裁决均在本轮停止，不打开
test、不进入H1b/H2、不启动新预算比较、不改论文。PASS仅为修正后的特定规范化算子响应，
不是顶刊创新、部署价值或全新前瞻盲验证；KILL也不证明所有方向辅助方法无用。

全部统计、两实现差异及最终裁决。只提交身份摘要或“验证通过”的结论不算证据交付。

代码、配置与科学结论按项目规则发布，大型原始影像、模型和中间量不进入普通版本库。
compact证据必须通过项目既有结果发布方式让B可读取，并从发布端实际取回验证可独立复算；
不能只说“本机保存”。在结果总账清楚并列原机器报告、B驳回理由和本轮修正结论，不覆盖历史、
不删除原产物。凡无法完成的环节如实列出，禁止用预期结果替代已执行事实。
