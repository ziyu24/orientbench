# SERVER 科学指令

## r024：新增影像能否替代特权可见性信息

目的：继承r023阳性，以新增图像而非真实可见性标签检验高度歧义能否被实际采样观测减少，
并比较固定反侧观测与三种同侧替代。仅为有限合成筛选，不宣称新方法或真实卫星可部署性。

完整继承3,125候选、原三图、48场景四组各12及192查询；seed1701保持不变，不新增随机重复。
这是旧成员上的配对后续探索，不是独立留出。HRSC2016不适配完整场景三视高程反演。

四臂分别只新增一张5×33的RGB图，165个采样：重复原slope=1图；slope=1错半采样间距；
同侧slope=0.75；反侧slope=−0.75。反侧视场绕固定场景中心镜像，倾斜大小、采样间距和
数量与同侧新角度相同，所有候选物体及查询投影均在视场内。各臂独立比较，不合并新增图。
等采样数不等于实际卫星获取成本相等。保持无噪声同色柱体条件，不改角度或采样密度追结果。

推断只用原三图和当前新增图精确过滤全部候选，禁止输入真实高度、场景编号、分层或真实
可见性。可见性只用于统计相容集合中可能的三比特模式数量，不能据此过滤候选。

保留全部零宽和共同遮挡查询；景内查询等权、景间等权。S=1−新均宽/原均宽，分母0记null。
报告总体和原四分组的各臂均宽、S、零宽/全高程范围计数及可见性唯一确定的查询数。
反侧通过需总体S≥25%、部分遮挡/深度边界各S≥10%；相对三个完整同侧臂中最小均宽的优势
除以原均宽，总体需≥10%、两个子组均≥0。不得逐查询按真值拼接最优同侧对照。

若只有绝对图像收缩门通过，保留有限新增图像收益，但停止反侧优势主张；全部未通过则停止
这套固定观测桥接方案。阈值是投入筛选标准，不是显著性或期刊标准；任何裁决均不自动训练，
不改成员、种子、角度、分辨率或阈值补救，不影响r020/r023阳性及r022停止结论。

独立重算全候选原/新图像、原成员、192查询相容集合、区间及统计。真值遗漏、空集、区间
扩张均须0；重复图臂与基线集合须逐项相同，否则属于实现无效，不能判科学阴性。
仅CPU，计算总墙钟不超过30分钟、产物不超过100MB；不训练、不下载数据或权重。
完成后将简短结果写入结果账，有效失败归失败账；原始产物保留，不制作PDF或额外长报告。
