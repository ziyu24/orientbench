# SERVER 科学指令

## r015 — 同支持、同像素预算下的方向价值：强反例实验

目标：检验方向信息相对充分旋转增强的独立属性决策增量，并把方向对齐与紧裁剪的
像素分配效应拆开。这是新的、有限预算的探索实验，不是上一轮重训补显著性，
不是已成立的顶刊方法，也不执行旧H1b/H2或风险selector。

科学细则以《R015 同支持方向价值探索协议》为准；实现、配置和实际运行证据必须一致。

1. 复用现有RarePlanes real及既有初始化。训练严格保留4,065个既定对象；分析严格保留
   7,416个既定calibration对象、25个来源component，保持原划分、标签和资格规则。
   该calibration已经被分析过，本轮只能称探索，不能称新的盲确认。保留test完全不打开。
   不新增数据、不下载模型、不扩大训练总体。
2. 三个训练策略：I为完整圆形支持、方向隐藏、全角度旋转增强；O使用完全相同的圆形支持
   和各向同性采样，但由GT长边轴对齐；T为相同GT轴对齐的紧矩形裁剪，专门诊断支持及
   像素密度变化。O/T训练均加入固定±10°均匀角抖动，不用脆弱的无增强分类器制造收益。
   I/O共享中心、无方向尺度、物理视野、输出尺寸和采样规则；O额外读取GT轴这一特权
   必须明示，不能声称三者信息完全相同或已经可部署。
3. 固定ResNet-50、ViT-B/16，两种实际输入尺寸96和224，种子1501/1502/1503，三策略，
   共36次全新拟合。每次40 epoch、相同优化步数、同种子配对初始化/对象顺序，使用
   最终epoch，不按calibration选checkpoint、seed、属性、尺寸或超参数。
4. 同预算主比较每对象两视图。I另报固定八视图均匀平均作为更高成本的强反例，明确其
   前向成本是两视图的四倍，不冒充等预算。O评估0、±5°、±10°、±20°；T只评估0°。
   角扰动曲线是受控压力测试，不是已测得的部署角误差分布。
5. 主终点是原三个二分类属性的等权宏平均、class-balanced × component-equal错误率。
   三属性逐项、每seed、每来源结果全部保留，不靠单个属性胜出。采用50,000次同步来源
   component bootstrap，完整重算固定同时区间；不得把7,416对象或三个seed当独立来源。
6. 探索继续条件：96输入下，两个架构的I两视图减O零扰动风险均至少2pp且同时下界>0；
   O还须在两架构上胜过I八视图（同时下界>0），并满足协议的有效性、基本效用及逐来源
   删除稳健性条件。2pp只是本轮是否继续投入的预定标准，不是顶刊标准，也不是旧H1a门。
   紧裁剪T单独胜出不能救回方向机制。不满足即结束本轮，不补seed、扩数据或调门；
   明确区分负结果、区间过宽和实现无效，不能统一包装成科学KILL。
7. 先完成必要的真实输入/render及统计反例检验，再训练。旧来源与旧结果不覆盖；新窗口
   必须按loc–CAT联合身份读取同一原COG，保留足够真实像素边界，不能复用错源校准图。
   交付全部实际生成/验证代码、36个模型训练记录、逐对象逐视图完整二类概率、风险分母、
   来源表、抽样索引、完整重算结果及成本表，使B能直接独立复算，不能只交摘要和布尔值。
8. 本轮允许上述训练和calibration前向，禁止test像素/前向/性能、detector训练、SAR、
   HRSC/RSAR新实验、selector/quality head/分数融合、论文修改及自动启动后续实验。
   无论结论如何，完成结果归档及可复算证据交付后停止；正结果也只交B判断是否值得
   设计真正的非oracle方法和来源外预测，不直接宣称TGRS/JPRS成立。
