# orientbench：当前唯一科学任务

## r016：真实多视角比较的元数据支持核查

**问题：SpaceNet4/MVOI 与 US3D/DFC2019 Track 3 的原生记录，是否支持同一训练地理单位上，
保留首幅观测、以近似同成本的近方向观测对照不同方向观测？** 本轮只查必要数据条件，
不检验任务收益、不拟合模型，也不把目录计数当作因果识别或顶刊新意。

继承 B 对真实 C 答复的执行说明与冻结配置。仅限上述两个数据版本的原生文本元数据、
训练文件名和地理边界；不读取影像/标签像素或建筑轮廓，不接触验证与测试结局。
HRSC2016 没有本问题所需的已核实同目标物理多视角与成像标定，故本轮不适配。

先确认原生 acquisition 身份、城市、传感器、处理产品、原生 GSD、获取时间、视线和太阳角度
约定及训练共同覆盖。MVOI 论文与官网的三个影像 ID 对应冲突须对照原件；US3D 的城市、
地理片和原始来源编号须正确联结，不能将不同裁片计作不同获取或混用原始与裁剪坐标系。
每个字段注明出处、单位、缺失及事前/成像后/依赖候选像素的可用时点。

设三幅不同来源为首幅 i、近方向 r、分离方向 j。固定主筛查：i/r 有向方位差 ≤10°、
视线夹角 ≤5°；i/j 方向差 ≥60°、视线夹角 ≥15°；r/j 离轴差 ≤2°、原生 GSD 比 ≤1.05。
分别报告 360° 有向视角与 180° 方位轴代理，后者不是独立测量的 PSF 主轴。
原生视线和以 off-nadir 为天顶角的射线代理分列，不将代理冒充实际地面入射方向。
离轴/GSD 敏感性固定为 1°/1.05、3°/1.10、5°/1.15，全部报告，不择优修改主口径。

在同传感器/产品且训练地理共同支持上，再核查 r/j 太阳向量夹角 ≤3°、三幅时间跨度 ≤600秒。
另报固定时间敏感性：跨度 ≤7天，r/j 距首幅的绝对时间差之差 ≤1天，其余条件不变；
这不证明场景没有变化。身份、太阳角、时间、共同支持或标定缺失都记未知，不填零或算通过。

分步给出合格、不合格和未知的原因、三联数、不同首幅/候选对/来源影像数，以及可核实的
过境事件、城市、传感器和空间连通分量数。给出原始字段见证与完整组合清单，避免把裁片数量
当独立获取样本量。没有匹配时报告限制它的实际条件，不现场放宽阈值或换数据集。

独立核实 PSF/MTF/噪声标定是否存在，以及任务真值定义和参考视角偏差；不从方位角、RPC、
标签或模型输出推定标定。整体视角的可见性收益与控制可见性后的模糊效应不可混称。

结束时只回答各资产的匹配支持和无法识别之处。数据不可取得与科学阴性分开；目录支持充足
也不代表任务收益、新意或物理机制已成立。本轮任何结果均不触发后续训练或自动补实验。
r015 及其他已停止路线维持停止，原实验偏离不追认，普遍零效应不宣称。
