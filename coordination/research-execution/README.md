# Research execution state

`AUTHORITY.yaml` defaults SERVER to `MASTER`. MASTER freezes the scientific route but proactively discovers existing server files, environments, datasets, caches and checkpoints, then autonomously creates or repairs environments, dependencies, engineering code/configuration, launch, scheduling, storage and recovery with `CONTINUE_AND_LOG`; a missing expected path is not by itself a reason to stop or ask B/C. Only an exact, digest-bound user control may enable `DOCTORAL`; DOCTORAL then owns scientific-route discovery, criticism, revision and end-to-end execution toward the top-venue goal. Decision events are append-only and enforce at most two B/C discussion rounds.

Agents use `python -m tools.workflow research begin|critique|block --request <yaml>` for the bounded decision chain, `research decision --id RDdddd` to read its current state, and `research authority-show|authority-set` for explicit SERVER authority. A direct or inherited executable conclusion writes the next `rNNN` `SERVER_PLAN.yaml`, including machine `acceptance_argv`, `execution_scope`, training `configuration_alignment`, and either `NEW_EXPERIMENT` or a B/C receipt-bound correction. Repairable engineering failures remain nonterminal `REPAIR_REQUIRED`: SERVER records `CONTINUE_AND_LOG` and recovers the same number. Only a frozen abnormal terminal consumes the next correction number. Every successful COMPLETE result requires B, C, or explicitly enabled DOCTORAL to run `execution scientific-assess`; all three rating workflows select a zone-matched journal through the built-in library. A later new experiment binds that receipt, while SERVER MASTER cannot rate venue level.

The project publication floor is TGRS or higher. Substantive B/C science cases include premise and epistemic checks, CAS 2025 final-edition assessment, comparable papers, strongest rejection case and model escalation judgment. GPU training prefers four cards while preserving the official global batch and optimizer learning rate through the bound project baseline. Production Git origin must use HTTPS.
