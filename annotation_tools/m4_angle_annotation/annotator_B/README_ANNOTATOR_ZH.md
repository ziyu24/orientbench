# M4 长边方向双标说明

1. 只观察任务包中的目标裁剪图，不得查看模型预测框、GT 角度、可靠性分数或另一位标注者的结果。
2. 标注目标 OBB 的长边方向。角度范围为 `[-90°, 90°)`，相差 180° 表示同一方向。可在图上沿长边拖动，也可直接输入角度。
3. near-square 目标若没有可辨识长边，选择 `Ambiguous`，不要猜测方向。
4. 遮挡目标：只有在可见轮廓足以稳定判断整体长边时才标角度，否则选择 `Ambiguous`。
5. 截断目标：依据可见部分和目标整体结构判断；若图像边界使整体方向无法可靠恢复，选择 `Ambiguous`。
6. `跳过` 只用于图像损坏、目标不在裁剪中或工具异常；普通困难实例应使用 `Ambiguous`。
7. 首次载入本目录的 `tasks.csv`，必要时选择 `crops` 目录。填写唯一标注者 ID 后开始标注。
8. 工具每次修改都会保存到浏览器本地存储；重新载入同一任务可恢复。结束时同时导出 CSV 和 JSON，并保留原文件，不覆盖旧导出。
9. A、B 两名标注者必须独立完成各自任务包，不得交换任务顺序、截图、角度或讨论具体实例。

提交文件：导出的 `annotatorA_raw.csv/json` 或 `annotatorB_raw.csv/json`。任务包自身是空白模板，不代表人工标注已经完成。
