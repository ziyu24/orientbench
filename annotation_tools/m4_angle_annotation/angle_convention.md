# 角度约定：le90 几何长边朝向

- 标注 OBB 几何长边的无向轴，不标船头、机头或车辆行驶方向。
- 角度范围为 `[-90°, 90°)`；`0°` 表示水平轴，逆时针为正。
- `theta` 与 `theta+180°` 表示同一条长轴。合并分析使用 `theta -> 2theta` 等价的最小周期差，结果位于 `[0°, 90°]`。
- 画布坐标向下为正，工具已自动转换为数学坐标的逆时针正角。
- 长宽近似相等、遮挡严重或无法可靠判断长边时使用 `cannot_determine=1`。
- 裁剪图只有定位作用，不显示 GT 框、模型框、GT 角、预测角或预绘制方向线。
