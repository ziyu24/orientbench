# r010 统计—机制闭环

本轮从同一批 full post-NMS prediction dump 构造 Core-6 固定剂量轨道。P、D、S 的完整 evaluator 结果按剂量记录；D 是固定 dose=0 匹配方向的 GT-directed diagnostic，S 同时保留正负方向分量。由于 SODA-A 两个 Core 单元在本轮执行窗口内未完成独立 evaluator，统一六单元 paired AP bootstrap 未运行，故机制门控不能通过，任何 r009 曲线不得升级为跨数据集科学结论。

当前唯一允许的结论是：r010 统计闭环未完成，v080 继续隔离旧的 certification headline；不得声称统一 AP75 knee、因果机制、NMS 效应或 deployable selector。
