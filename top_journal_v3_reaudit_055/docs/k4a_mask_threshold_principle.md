## 冻结判据（跑前设定）
工程语义："在更严格阈值 τ=0.75 下，一个 **δ\*=15°** 的角度扰动应使 IoU 跌破 0.75" —— 即认为
**只有当 δθ_0.75(ar) ≤ 15° 时，朝向在 τ=0.75 下才是可辨识/可评估的**。δ\*=15° 与 τ=0.75 在跑前冻结。

## 几何：角度容忍度 δθ_τ(ar)
面积归一共中心矩形绕中心旋 δθ，δθ_τ(ar)=保持 IoU>τ 的最大 δθ：

| ar | δθ@τ=0.5 | δθ@τ=0.75 |
|---|---|---|
| 1.0 | ~89.5°（永不跌破 0.5）| 25.5° |
| 1.3 | ~89.5° | 23.0° |
| **1.6** | 69.5° | **19.5°** |
| 2.0 | 47.0° | 16.0° |
| **2.1（derived）** | ~45° | **≈15.0°** |
| 3.0 | 27.5° | 10.5° |
| 4.0 | 19.5° | 8.0° |
| 8.0 | 9.5° | 4.0° |

## 推出的临界 ar
**derived ar\* = 2.1**（δθ_0.75(2.1) ≈ 15°）。现用的 **ar≥1.6 对应 δθ_0.75≈19.5°**，即 1.6 比 derived-2.1
**更宽松**（保留更多近方形）。

## 判定与建议
- **derived-ar=2.1 与 1.6 明显不同**（δθ_0.75 判据下）→ 依 §5.8，**后续正文主口径应改为 derived-ar=2.1**，
  ar≥1.6 与 ar≥1.3 作 sensitivity。derived 阈值把更多"τ=0.75 下角度弱可辨"的中等长宽比目标也剔除，主结论更保守。
- 判据依赖 δ\*：若取 δ\*≈19.5° 则 derived≈1.6；本文以 δ\*=15°（τ=0.75 下 15° 扰动显著改变 IoU）为冻结判据，
  故 derived=2.1。此依赖已如实登记，δ\* 跑前冻结、不追后改。
- **K4a 初步判定：PASS**（masked 阈值有明确几何原则；给出 derived-ar 与三阈值敏感性、各数据集 mask 比例）。
  正文口径迁移（1.6→2.1 主、1.6/1.3 sensitivity）留待主稿修订，不在本轮改 frozen assets。
