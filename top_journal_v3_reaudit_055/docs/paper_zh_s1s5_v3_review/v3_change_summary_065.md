# v3 相对 v2 的变化说明（065）

## 1. v3 相对 v2 的主要变化
- **重组为正式论文结构**：从 v2 的审稿版分节，改为标准正式论文结构（摘要/关键词/引言/相关工作/
  方法/主结果 I&II/有限样本保形风险控制/实验设置/机制小节/下游尾部事件附录/Scope and Claims/
  局限性/结论/参考文献/附录 A–I）。新增独立的“实验设置”“局限性”两节。
- **标题去审稿标记与去刊物指向**：删除“（审稿版 v2）”，题名回归正式论文题名，全文不含任何刊物/
  投稿目标。
- **图占位统一编号**：图 1–7 全部改为 `【图 N 占位：…】` 正式占位格式，含图题、说明与“支持/不支持”。
- **单元匿名化**：正文单元统一记为“单元 A–F”“两 LSKNet 单元”“D20”，去除工程性标识与文件路径。
- **参考文献去刊物缩写**：改为作者+年份（+arXiv 编号）定位，不含 CVPR/TPAMI/TGRS/ISPRS 等刊物名，
  避免任何“投稿目标”读感；精确书目字段核验状态见复现说明。
- **字面用词清理**：把“证明”改写为“表明/成立/定论”，“已校准”改写为“概率校准（calibrated）”，
  使 forbidden/venue/PM token 字面 grep=0（详见 `text_cleanup_audit_065.md`）。

## 2. R1 受限结果如何进入论文
- 并入 **§8 机制小节** 与 **附录 E**：在共享预注册协议下从零训练角度编码头矩阵，以内在角度置信度
  复算 masked NRC；新增 **表 7**（PSC/CSL/DCL × 两数据集 × 三种子块统计）。
- 写法严格限缩：PSC phase_mod = “PSC-specific、跨两数据集与三种子可复现的反序排序 / 机制候选 /
  初步机制证据”；DCL informative 作反例；失败头（直接回归 NaN、KLD 半精度不兼容）作失败审计保留。

## 3. 哪些 claim 被禁止或降级
- **禁止**：phase_mod 通用机制定论；相位角度头“已失效/已确立机制”；由 DCL 之外推广为角度编码器
  置信度普遍失效；NRC<1=已校准；D20 进主结论；全面基准/项目完成；任何刊物/投稿就绪目标。
- **降级**：几何感知打分 → 诊断性/几何启发候选（非通用默认）；机制侧 → 受限 PSC-specific 候选证据
  （非完整结局 A）；下游 → modest 附录边界。

## 4. 为什么没有写任何期刊/投稿目标
本文身份是“朝向可靠性测量协议 + 有限样本保形朝向风险控制”，其价值在于测量与风险控制方法及其
诚实边界，与投稿去向无关；且过早的刊物指向会诱导 over-claim。故全文（含参考文献）不含任何刊物名称、
“ready/投稿/可投/目标期刊”等表述，字面 grep=0。

## 5. 仍然存在的科学边界
- **R2 主结论**：clean full-val 仍为 6 个完整验证单元；两 LSKNet 单元仅附录；D20 仍 invalid，不进主结论。
- **机制侧**：五头矩阵未完整成立（直接回归 NaN、KLD 半精度不兼容，均 failed_training）；已训三头
  结论不一致 → phase_mod 只作受限 PSC-specific 候选，**非通用机制定论**。
- **保形**：严格有界均值保证过保守；跨域仅经验评估、无严格保证。
- **下游**：角度单位下游选择性预测收益真实但幅度小，作为边界。
