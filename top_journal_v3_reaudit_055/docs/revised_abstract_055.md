## 中文摘要
定向目标检测（oriented / OBB detection）以 mAP 为主要评价指标，但 mAP 在给定 IoU 阈值下对朝向误差高度不敏感：我们证明，在保持交并比大于 0.5 的约束下，可对预测框注入平均约 35° 的角度扰动而 mAP@0.5 完全不变，与此同时朝向误差与 AP75 急剧恶化；该不敏感性由目标的长宽比与 IoU 阈值共同门控——近方形目标的朝向在 IoU 上几乎不可分辨，形成可靠性“悬崖”。据此我们提出一套 **朝向可靠性测量协议**：在剔除近方形病态实例（长宽比≥1.6）的冻结口径下，以归一化风险-覆盖曲线（NRC）、AURC 与分位风险刻画“检测置信度对朝向误差的排序质量”。测量表明，检测置信度对朝向误差的排序在良态（细长）实例上大体校准；先前报告的“置信度反校准”实为把近方形病态实例并入统计所致的合并假象。在此协议上，我们给出 **有限样本朝向风险控制**：以保留集校准、审计集验证的 split-conformal / CRC，在“优于平均可靠性”的工作区提供带弃权的尾部角度误差保证；进一步比较可套接的可靠性打分（检测置信度、几何感知选择器、测试时增强一致性、角度编码器内在置信度），发现在固定保证下 **几何感知选择器一致取得最高覆盖**，构成推荐的“conformal 保证层 + 几何选择器”默认方案。机制层面，定向角度编码器（PSC）的内在置信度即便在良态实例上仍显著与朝向误差反序，提示编码器级的可靠性缺陷，是 mAP 与检测置信度均无法揭示的。跨数据集迁移下保证会退化，按长宽比分层校准可部分缓解但不提供严格迁移保证；朝向可靠性选择带来的下游定位收益真实但幅度很小。综上，本文将朝向可靠性从“测量”推进到“有限样本风险控制”，并给出可复现的协议与诚实的适用边界。
