# R4 —— 尾部事件下游任务

> masked ar≥1.6，真实 052 匹配表，方向类目标，仅 OBB 长边几何朝向（不涉语义航向）。severe orientation error 定义 err>15°。数据：`reports/r4_tail_event_downstream.csv`。

## 设计
在方向类目标（船/港口/车辆/飞机等）上，定义严重朝向误差 err>15°，比较不同打分（检测置信度 / size-linear / 几何感知）在固定覆盖下的严重误差率；selector 在 D_fit 上训练。

## 结果（严重误差率 err>15°，越低越优）
| 单元(方向类) | 基率 | 严重@70 检测 | 严重@70 线性 | 严重@70 几何 |
|---|---|---|---|---|
| SODA#4 | 0.0054 | 0.0020 | 0.0014 | 0.0017 |
| DIOR#3 | 0.0011 | 0.0000 | 0.0000 | 0.0000 |
| FAIR1M#24 | 0.0056 | 0.0000 | 0.0000 | 0.0020 |
| DIOR#22 | 0.0013 | 0.0002 | 0.0002 | 0.0006 |

## 结论
在良态方向类目标上，严重朝向误差**本就稀有**（基率约 0.1–0.6%）；各打分在 70% 覆盖下可将其降至近零，**检测置信度常已足够**，几何感知打分未一致更优（个别单元略差）。因此严重误差尾部事件的下游收益**真实但幅度小**，作为附录，不主张下游实用性已证明，不影响主线。只报告几何朝向，不作语义航向 claim。
