# r020：同两模型、同两次推理下的额外影像价值

署名B。r019已验收，当前r020尚未执行；没有C的新回写。

## 要回答的问题

在训练区域确定的位置校正之后，把两次计算用于同一首幅影像的两个既有模型，还是分给
两个真实视角，哪一种风险更低？r018的事后同图集成、r019的单模型平移分别提供了线索，
没有共同回答这个问题。此轮是固定强替代检验，不实现选角器，不追认PSF或顶刊方法。

两边可使用同样的两份既有末轮模型，每个实际动作都是两次前向。额外影像动作需要第二幅
影像，同图动作只需要首幅；因此模型/推理预算相同，获取要求不同，不能称总经济成本相等。
这里不测真实获取价格，也不声称已穷尽最优模型与所有可用替代。

## 冻结规则与比较

- 原四视角A/B/U/V、256训练区域、128评估区域、16空间块、实际标签与预处理均不变。
  既有seed1701、1702是两模型动作的组件，不是新增训练重复；不估计跨seed稳定性。
- seed1701固定沿用r019的四个位移；只给seed1702新增训练区域四视角前向1024图。
  用与r019相同的中心384、固定权重、[-32,32]整数范围及并列规则拟合四个全局位移。
  完整损失面、全部训练图所选/零位移直接损失误差≤1e-10，冻结保存后才打开评估概率/标签。
  边界最优不扩大范围；仍报告冻结结果和局限，不逐区域拟合、不重训。
- 所有评估复用r018已验收的两模型完整四视角图。主臂为中心384、各模型各视角固定校正；
  中心384零位移为描述性对照。直接448原生标签只作同预测、同权重、同位移敏感性。
- 同图动作S_i=(p1_i+p2_i)/2。真实双图动作有预先固定的两种分配：
  C_ij12=(p1_i+p2_j)/2、C_ij21=(p2_i+p1_j)/2。每种只需两次前向，
  两种都评估，损失平均相当于不读标签、等概率确定模型分配的期望风险。
  这是对两种动作结果求均值，不是对四张预测图求均值；后者增加推理预算且因非线性损失不同。
  不按评估集选更好模型分配。保存每种分配的完整逐区域损失及IoU计数。
- 两个联合主比较为G_A=L(S_A)−[L(C_AV12)+L(C_AV21)]/2和
  G_B=L(S_B)−[L(C_BU12)+L(C_BU21)]/2；正值表示固定计算预算下双图更好。
  不用一个总体平均掩盖某一侧不足。AU/BV冗余动作、交叉差I和全部单动作损失为次要描述。
- 块内区域等权、16块等权；PCG64(17017)、20000次配对空间块bootstrap。
  两个主比较各报97.5%双侧区间（分位点.0125/.9875，Bonferroni近似处理两项比较），
  另报描述性95%区间。Bootstrap覆盖率是近似的，已使用的评估集也不变成新盲确认。
  IoU每块先交并比、再块等权，两个分配的比值再平均，不将两种分配计数混为单次动作。

## 判读

只有两侧主区间下界均为正，才可说本轮在两个固定参考方向均支持额外影像优于这个具体
同图双模型替代；仍不支持一般机制、新来源外推或所有强替代均不足。
一侧跨零就报告该方向不确定，不改用较弱TTA或总体交叉差代替；一侧为负则报告反向结果。
两种标签口径若方向冲突或个别模型分配相反，完整披露，不挑更好口径/分配。
不因结果追加模型、种子、epoch、尺寸或新的校正自由度，不自动进入其他实验。
完成后归账并结束；原停止的方法族保持停止。
