**2．B 的可行集合候选，究竟离旧方法有多远？**

先把对象写清楚。设 \(s\) 是完整场景，包含建筑、遮挡物和相关几何；\(\eta\) 是有明确范围的相机、辐射和噪声未知量。观测相容集合为

\[
\mathcal C(y)=
\{(s,\eta):d(F(s,\eta),y)\leq \epsilon\}.
\]

对任务量 \(T(s)\) 输出

\[
\left[\inf_{\mathcal C(y)}T(s),\ \sup_{\mathcal C(y)}T(s)\right].
\]

**这个表达式本身没有构成新方法。**最致命的对应关系如下：

| B 可能采用的实现 | 我的判断 |
|---|---|
| 轮廓反投影并求交，得到空间包络 | 属于 visual hull 的基本思路；换成卫星投影模型不足以产生方法新意 |
| 加入颜色、深度、遮挡一致性筛除场景 | 不必严格等于 visual hull，但进入已有空间雕刻、立体匹配与逆问题求解范围 |
| 固定任务量，优化其余未知量，按残差或似然阈值保留 | 有概率模型时通常就是 profile likelihood 或相关置信集反演；只有确定性误差界时属于集合成员估计，不能都叫似然 |
| 找两个观测近似相同、任务答案不同的场景 | 是有效的不可辨识性见证，但“双解反例”本身不是新颖机制 |
| 生成多个合理补全，报告最大最小值 | 只得到已搜索候选的范围，不能证明完整上下界，更不能证明范围外没有解 |

还有三个比命名更严重的问题。

第一，**visual hull 通常提供外包络，不自动提供“确定存在”的实体内核。**一个位置落在所有轮廓锥内，并不表示每个相容场景都在那里有建筑。

第二，**“可见部分标注”不能直接充当完整轮廓。**未标建筑可能是被遮挡，不能据此当作自由空间剔除。若使用这类负约束，可能得到越来越窄、却把真实场景排除的集合。

第三，集合随观测增加而缩小，需要保持同一个场景变量、相容的未知量定义和固定约束体系。它不是“新图必有用”的证据；错误约束也能让集合快速缩小。重新估计阈值和噪声后，某些统计区间甚至不保证逐样本嵌套。

按 B 对 GeoRay、立体匹配区间和几何置信校准工作的转述，**RPC 可观测性、高程基准、普通多视融合、区间与覆盖率校准，都应先按已有工作覆盖处理。**不能因尚未逐条核实某篇论文，就把相邻问题视为空白。

我明确建议放弃以下包装：一般可行集合、一般非唯一性、普通区间校准、普通选角、普通高度与相机偏差分离，以及“独立物理足迹”这一尚无真值支撑的表述。

**3．我与 B 的核心分歧：先证明有值得恢复的信息，再设计恢复方法。**

“未知遮挡下有非唯一性”几乎肯定能构造出来，特别是完整地面足迹。多幅俯视图都看不到的墙脚、退台或被相邻建筑遮挡的结构，可以保留相同可见屋顶而改变足迹。

这说明最坏情况下不能唯一恢复，但**不能说明现实数据中问题有多严重，也不能说明有一种方法能利用现有影像解除它**。如果把这些不可见结构用强建筑先验补齐，获得的是先验帮助，不应叫作观测已经确定。

所以，我不建议立即开发“非唯一性见证网络”。我的替代建议是一项明确的研究筛选：

> **在相机几何已知、输入图像固定的条件下，即使额外给出真实遮挡关系，任务不确定范围是否仍几乎不能改善？**

若答案是“几乎不能”，继续开发遮挡估计器缺少任务价值。若改善很大，也只说明存在信息上限，尚未说明遮挡关系能从现有图像中学出来。

**4．唯一建议的首轮：真实遮挡信息的任务价值上限。**

这是一个低成本筛选实验，**不是已经成立的顶刊方法，也不恢复任何旧候选。**

**数据与任务。**首轮采用具有完整场景几何的、固定小型合成三视场景，估计预先指定地面位置的最高表面高程。选择表面高程，是因为它能由完整场景直接定义；不将其改称地面足迹。

优先核查 WHU-OMVS 是否实际提供满足需要的场景几何、相机和可重建可见性。你提供的材料只确认它是合成资产，**尚不能确认这些字段可得**。若不满足，使用透明的简单场景和 CPU 射线渲染完成机制筛选，明确只得到合成结论。HRSC2016不适配此问题。

建议固定 48 个小场景，均衡覆盖无遮挡、单侧遮挡、多视共同遮挡和深度边界；场景规则在计算结果前固定，仅用一个固定种子。这个数量用于判断明显的机制空间，不用于宣称真实城市总体效果。

**三个对照，全部使用相同影像和几何：**

1. **普通匹配基线：**立体匹配代价及稳健区间，允许异常匹配。
2. **强基线：**显式共享三维场景和遮挡关系，将未知遮挡作为潜变量联合优化或消去。不能故意拿“把遮挡当独立高斯噪声”的弱模型充当最强对手。
3. **遮挡 oracle：**在强基线基础上，额外给出真实的首交表面对应关系与可见性；不提供真实高度、完整深度图或目标答案。

第三组获得了额外信息，必须明确标作上限，不能作为公平方法胜利。强基线本身就是对 B 候选的近邻检验：若 B 所谓新方法只是其另一种实现，应直接承认。

**主终点。**在固定查询总体上，比较强基线与 oracle 的高程区间宽度，并同时报告真值遗漏率、空集合率和没有实质约束的区间比例。完全遮挡和推断失败的查询必须保留。

能够完整枚举的小场景，使用精确相容范围。若只能数值搜索，必须区分已找到的候选范围与有证明的外界；局部优化输出不能冒充完整区间。若采用统计阈值，则只在独立开发场景确定，评估场景不重新调覆盖率。

**建议预先冻结的实用假设：**

> 在可接受的真值遗漏率下，真实遮挡信息能使强基线的平均区间宽度至少下降 25%，且改善不是仅由少数场景或删掉难例造成。

25% 是我建议用于决定是否继续投入的实用阈值，不是已有文献结论。阈值需要在看结果前固定；不能看到 12% 后改称“已有明显潜力”。

**停止条件：**

- oracle 相对强基线的改善不足预定实用阈值：停止以“估计遮挡关系”为核心的新候选投入。
- 优势仅存在于弱基线比较，强基线已达到相同效果：停止方法创新包装。
- 变窄来自漏掉真值、删去共同遮挡查询或收紧未披露的形状先验：不接受有效改善。
- 搜索范围无法证明、oracle 偷带目标高度：实验无效，不能写成科学阴性或阳性。

即使通过，也只得到“完美遮挡信息可能有用”的上限结果。**下一步真正困难的是证明该信息能由允许输入获得，并超过已有遮挡感知推断；oracle 阳性不自动授权训练。**

**5．真实数据与顶刊判断。**

WHU-TLC 的真实三视、RPC 和 DSM，使它有可能承接后续表面高程验证，但目前不能承接完整物理足迹保证。还必须核实 DSM 来源、误差及与影像处理的依赖关系；经外部精校正的 RPC 也不能支持“无控制条件下解决绝对几何”的主张。单过境三视不能充当独立多过境确认。
