# r019：训练区域确定的全局位移解释性对照

## 科学问题及现实意义

r018完整概率验收后，固定真实互补视角相对冗余视角的交叉损失差I为0.077705，
但尚未排除系统性位置偏差，事后同图双模型集成也使A方向收益区间跨零。
本轮只问：用训练区域估计的每视角统一平移，是否减小已观察到的交叉差？
这是决定是否继续投入机制研究的低成本解释实验，不是新方法或顶刊命题的确认。

MVOI原论文指出离轴成像下地面建筑轮廓与可见屋顶不能保持重合，并存在遮挡。
依据：[Weir等，ICCV 2019，图1及数据说明](https://openaccess.thecvf.com/content_ICCV_2019/papers/Weir_SpaceNet_MVOI_A_Multi-View_Overhead_Imagery_Dataset_ICCV_2019_paper.pdf)。
这里由文献提出的推测是“平均系统位移可能解释一部分风险”；未证明本模型还有该偏差，
也未把全局平移等同于建筑高度相关校正、RPC/三维重投影或PSF机制识别。
模型可能已经学会部分位移补偿，因此估计为零或校正无改善也可能是操纵不足。

## 冻结比较

1. 固定复用r017末轮seed1701，沿用实际输入处理、标签和训练权重π=0.10128044595523755。
   按原预设种子编号取第一个，不按效应选种子；新问题默认单种子探索，不复述跨seed稳定性。
   四视角顺序固定A/B/U/V，原256训练区域与128评估区域、16空间块均不变。
2. 只新增训练区域四视角前向，共1024图；没有神经网络训练。每视角从256训练标签估计
   一个全局整数(dy,dx)，总计8个坐标参数。候选各为[-32,32]，含零，不增加自由度或边界。
   450米/448像素对应约1.00446米/像素，范围约±32.14米；这是有限控制范围，不是假定真实位移上限。
3. 所有候选共同使用中心384×384标签。q[y,x]=p[y+dy,x+dx]，标签不移动，无插值、填充或循环。
   目标为每图固定加权BCE的均值，再256图等权。概率裁剪沿用[1e-6,1-1e-6]。
   所有既有有效掩码应全真；变化则报告输入不符，不删除样本或改成候选相关掩码。
   最小值1e-12内并列时，依次取位移平方和、dy、dx最小者；保存全部4张65×65损失面。
4. NumPy零填充FFT计算线性相关，仅取valid位置，不作周期相关；随后对全部256训练区域
   直接计算零位移和所选位移BCE，平均值与FFT需相差≤1e-10。四个位移和输入证据落盘之后，
   代码才读取评估概率与标签。训练标签参与估计，评估标签不参与选择；评估集已见，仍是事后解释。
5. 同一批既有r018概率分别报告原全448、中心384零位移、中心384固定校正三臂。
   只用两个中心臂计算位移效应；全图与中心零位移差用于显示裁剪影响。
   A/B的完整逆旋转图应用对应参考视角的同一平移，再作概率平均；不恢复旧单行TTA。
   缓存标签为主，原生直接448标签裁剪为敏感性；后者不重新估计位移、权重或训练模型。
6. I仍为[L(A,U)−L(A,V)+L(B,V)−L(B,U)]/2；r019主比较D=I_零位移中心−I_校正中心。
   D>0仅表示交叉差减小，不表示总体风险改善。必须同时报告残余I、ΔA/ΔB、两个TTA收益、
   四单图与四融合风险和IoU，以及各单图/组合的校正风险改善。
   单图平均风险改善是四单图损失改善的等权均值；所有逐区域差先配对再空间汇总。
7. 每块内区域等权，16块等权；固定PCG64(17017)、20,000次配对空间块bootstrap和原块顺序。
   单seed不提供优化波动不确定性，空间块也不是独立过境。D的区间仍属已使用评估集的事后
   分析，其余区间描述性报告。不把区间跨零当证明为零，不计算不稳定的“因果解释百分比”。

## 一次执行后的判读与停止

- 若校正能改善评估单图风险，同时D为正且区间支持下降，说明简单系统位置偏差可解释部分
  交叉差；这会削弱“全部来自新观测信息”的说法，不证明完整物理机制。
- 若残余I和TTA收益仍在，只说明这个全局位移控制不足；不证明所有标准校正无效或PSF成立。
- 若没有评估风险改善，训练拟合不能迁移，或最优点落在搜索边界，明确标注控制解释力不足/
  范围截断；不据此否定位置机制。仍完成冻结的评估，不自动扩边界、逐屋拟合或重训。
- 无论结果如何，本任务一次结束，结果归账；不自动追加种子、神经模型、数据集、选角器。
