## B 接受什么，修正什么

C 把问题收紧为保留首幅观测后的第二幅观测边际任务收益，比泛称“方向有价值”明确。
B 接受其先检查资产的建议，但下列问题仍未解决，不能直接继承整套实验：

1. **可见性视角是 360° 有向量，模糊主轴是 180° 无向量。** 相反观测方向可能暴露不同立面，
   却具有同一个模糊轴。target azimuth、RPC 与已标定 PSF 不是同一东西；遥感地面入射角也不应
   无说明地用卫星 off-nadir 替代。若只测到整体视角收益，结论就只能落在整体观测变化。
2. 如果遮挡变化正是互补收益的原因，将遮挡一概作为“需要排除的混杂”会控制掉机制本身。
   “整体视角收益”与“控制可见性后的模糊方向效应”需要不同估计目标。后者需要独立测量条件，
   不能靠结果回归声称已经分离。候选影像的实际质量、云量若来自获取后的像素，也不能放进宣称
   获取前可用的预测器。现有档案选图与未来卫星获取必须分开。
3. 在同一过境轨迹中，方位、离轴角与原生 GSD 高度联动。增加同一影像的裁片数不增加独立
   获取事件数；回归残差、随机打乱或配对均不能自动把这种观测数据变成因果实验。
4. 可逆无噪声算子不保证带噪风险不变，逆算子可能放大噪声。Fisher 信息之和相同只限制相应
   正则条件下的局部估计，不能直接推出一般任务 Bayes 风险相等。可用的基本否证例是：若给定
   首幅及冗余观测后，候选观测与任务标签条件独立，则它没有额外 Bayes 信息收益；这不是新定理。
5. MVOI 的参考视角标注有可见性选择；US3D 的标签任务、城市、传感器和成像产品又不同。
   Atlanta/WV-2 到 JAX/OMA/WV-3 同时改变多个因素，不能称为纯地点迁移或仅传感器迁移。
   “加一个数据集就达到某期刊”没有科学依据。r016 不设期刊升档规则。

新颖性也没有因 C 的工作名而成立。B 复核了 Xu 等原文在 MVOI 上的主动相机配置实验，
Qin 的元数据像对质量预测及 Gomez 的模拟完整性/像对选择；普通任务驱动选角或增加元数据
仍与直接近邻重合。ATRNet-LUDO 当前原文仍称数据/代码即将发布，不能计作已经可运行的资产。
来源：[Xu 等](https://www.sciencedirect.com/science/article/pii/S0925231221013953)、
[作者上传稿](https://www.researchgate.net/publication/354967713_Dynamic_camera_configuration_learning_for_high-confidence_active_object_detection)、
[Qin 作者说明](https://github.com/GDAOSU/Publications/blob/main/isprs_qin_critical.md)、
[Gomez 等原文](https://openaccess.thecvf.com/content/WACV2023/html/Gomez_Improving_the_Pair_Selection_and_the_Model_Fusion_Steps_of_WACV_2023_paper.html)、
[ATRNet-LUDO](https://arxiv.org/abs/2607.09078)。

### 1. 定向确认入口，取得小型原件

先查固定 dataset 根中这两个数据集的已登记入口/别名（若有），不递归扫盘。
没有现成文件时，只取官方独立原生文本元数据、训练文件名清单与训练地理边界文本：

- SpaceNet：从[官方入口](https://spacenet.ai/off-nadir-building-detection/)对应的
  `s3://spacenet-dataset/spacenet/SN4_buildings/` 定向列举元数据对象。页面展示的每幅约 7GB
  tar.gz、整集与样例影像包均不下载；不能为了寻找几个 XML 流式扫完整影像包。
- US3D：以[作者 DFC2019 data 说明](https://github.com/pubgeo/dfc2019/tree/master/data)及其
  [IEEE DataPort 入口](https://ieee-dataport.org/open-access/data-fusion-contest-2019-dfc2019)
  为准，优先找独立 `Track3-Metadata` 包。不要混入 Track 1/2 或后续不同 US3D 版本。
  作者目录还提供 torrent 描述文件，可只读其中训练文件名清单；不得启动 P2P 下载或上传。

先检查响应和大小，下载器按实际读入字节累计限额；未知长度也不得越限。只允许文本元件。
如训练清单/边界在大 ZIP 中，只有支持精确 HTTP Range 时才可取目录及指定文本成员；
不接受完整影像响应，不通过下载标签像素包取得边界。元数据和 split 清单混有非训练名字时，
只用于识别训练成员，不读取其他分区内容、不据其他分区几何选实验。

遇到登录要求、无权限、独立包不可取得或超预算，记具体 URL、响应、可确认大小及未得到的字段，
继续已取得来源的核查后结束。网络失败不是资产不存在或科学效应为零，不绕过访问控制、不购买。

### 2. 原件身份、角度约定和信息可用时间

每条提取记录保留来源文件/字段、原值、单位、转换式、缺失原因及获取时点。至少列出：
数据版本、城市、sensor/product、catalog ID、source ID、获取 UTC、原生 GSD、off-nadir、
卫星方位/高度角、太阳方位/高度角、RPC/原始坐标系及已有独立 PSF/MTF/噪声标定的出处。
没有的信息写 unknown，不填 0，不用图像平均亮度、任务标签或模型输出来推断。

获取时点按“事前计划可得 / 成像后元数据可得 / 依赖候选像素 / 未知”逐字段注明。
原生平均值、最小/最大值、重采样后像素大小必须分开；本轮匹配原生全色 GSD 的同口径均值，
若只有范围就保留范围并报告可判定性，不能挑最有利端点。

MVOI 逐条对照上述三个冲突 ID；无法解决的来源不计入“身份已核实”组合。
US3D 用版本、城市和 source ID 联结原生 IMD/RPB 与训练文件名。作者约定
`JAX_163_010_RGB` 表示 JAX 城市、163 地理片、010 原始影像；010 在不同城市不能串接。
同一来源影像的不同裁片不是不同获取。重复 ID/冲突字段不静默覆盖，哈希只能绑定文件，
不能证明身份或角度语义正确。

RPC 有无、指向哪个原始/裁剪坐标系要分别确认。作者说明 Track 3 RGB 中的 RPC 已经调整
配准/裁剪；原始 RPB 不可直接当作裁片 RPC。只读文本不足以完成该确认时如实留空，
不要为完成它而打开 RGB。原生卫星高度角若定义清楚，可用地面天顶角 `90°−elevation`
与统一方位计算视线夹角；只有 off-nadir 时保留代理并把真实夹角记 unknown。

### 3. 按固定筛查逐项列出支持与缺口

先按同一版本、城市、传感器和处理产品分组，枚举不同来源的有序 `(i,r,j)`。不得把空间
互不重叠的 acquisition 拼成“同一目标”。几何代理与真实视线检查分列；阈值见冻结配置。
已有程序只提供目录代理筛查，SERVER 如需适配原生字段，只在 `src/` 增加本轮小型解析程序，
并检查 ID 冲突、单位、角度周期及缺失值行为，不创建通用运行框架。

对主口径和全部三组敏感性，依次报告以下条件之前/之后的合格、不合格、未知数量及原因：

1. 原生身份可确认，r/j 离轴/GSD 可比；i/r 近方向、i/j 分离方向。
2. 已有训练文件名和边界支持三幅共同地理单位。目录覆盖只能证明几何候选，不能证明同一
   建筑仍存在、每幅都可见或包含同样有效像素；没有训练成员表就不能填共同支持数量。
3. r/j 太阳向量夹角 ≤3°，三幅获取时间最大跨度 ≤600 秒。缺时间或太阳角均为未知。
4. 另报固定时间敏感性：最大跨度 ≤7 天，且 r/j 距首幅的绝对时间差之差 ≤1 天；
   其余条件不变。这不是主结果，也不证明建筑无变化。太阳向量必须从有定义的方位/高度角
   计算，不能只比太阳方位。

每种口径同时报告三联数、不同首幅/候选对/来源影像数、明确的过境事件数、城市/传感器数，
以及能从边界确认的空间连通分量数。无法核实事件归属或空间连接时标未知，不按裁片数替代。
输出代表性三联的原始字段见证与完整组合清单；若为空，给出每步减少的原因和最近条件差距，
不现场调阈值救回。若有独立 PSF 标定，单列来源、适用波段/位置和不确定性；否则物理 PSF
方向机制仍不受这些数据支持。180° 方位代理通过也不能取代该项。

任务真值只核实训练标签的来源、定义和配准说明，不读取标签像素/建筑轮廓。
US3D 官方 Track 3 提供 DSM/类别/地理 TXT，并不自动等于与 MVOI 相同的实例任务。
按 [2019 DFC 官方说明](https://www.grss-ieee.org/community/technical-committees/2019-ieee-grss-data-fusion-contest/)
及作者文件约定核实分区；不把原验证/测试真值当成训练资产。
