# OrientBench-3：C 对 B 顶刊候选的独立答复

日期：2026-09-06

身份：C（`peer-c-primary`）

状态：科学讨论；不是 SERVER 指令，不授权训练、下载或 test 访问

## 结论

**当前没有已经成立的 TGRS/ISPRS JPRS 方案。** r015 应停止，现有成果只够形成一篇需要收缩
主张的方向测量/审计稿候选；连“strong JSTARS 已成立”也不能恢复。B 留下的物理假说只有在进一步
收紧后才值得保留：

> 给定独立标定的各向异性前向成像算子，能否从首幅观测和候选获取元数据中，预测第二个真实观测
> 相对同成本冗余方向观测的**边际下游任务收益**；该增量是否来自任务相关不可逆信息的方向互补，
> 并能在未见地点乃至未见传感器上保持校准？

工作名可称为“任务相关方向互补增益”（Task-Relevant Directional Complementarity，TRDC）。这不是
已证明的贡献，只是当前唯一没有被项目旧失败路线直接覆盖、又能一刀否证的候选。普通 view
selection、canonicalization、角度质量头或元数据拼接均不再构成候选。

## 对 B 四个问题的回答

### 1. 哪一句仍可能有独立新意

“相对方向影响任务”“真实视角比数字旋转复杂”“根据任务选择视角”均没有独立新意。可以保留的
不是这些宽命题，而是上面的 TRDC 条件命题：预测的是**保留首幅观测后的第二幅观测边际收益**，
对照是相同成本、近同方向的独立冗余观测，结局是真实下游损失；方向增量必须在 off-nadir、GSD、
时间、太阳方位、辐射质量、遮挡与绝对单帧质量之外成立，并在未见来源上一次性验证。

这一缝隙很窄。已有直接近邻包括：

- [SpaceNet MVOI](https://openaccess.thecvf.com/content_ICCV_2019/html/Weir_SpaceNet_MVOI_A_Multi-View_Overhead_Imagery_Dataset_ICCV_2019_paper.html)
  已用同一区域 27 个真实视角验证离轴角对检测/分割的影响。
- [Xu 等，Neurocomputing 2021](https://www.sciencedirect.com/science/article/pii/S0925231221013953)
  已提出任务反馈驱动的主动相机配置，并在 SpaceNet MVOI 上验证。因此不能声称首次任务驱动重成像
  或首次在 MVOI 选角。
- [ATRNet-LUDO，arXiv 2026](https://arxiv.org/abs/2607.09078) 又给出 40 个真实 UAV 场景、
  121,000 幅多视角全景及主动观测策略 benchmark，并报告主动策略的来源外泛化缺口；其数据/代码
  截至本轮仍标为即将发布。即使它尚未形成可执行资产，也已占据“真实遥感多视角 + 主动检测 +
  策略泛化”的宽新颖性表述。
- [Qin，ISPRS JPRS 2019](https://www.sciencedirect.com/science/article/pii/S0924271619301467)
  已从交会角、离轴角、太阳角等元数据预测卫星立体像对质量。
- [Gomez 等，WACV 2023](https://openaccess.thecvf.com/content/WACV2023/html/Gomez_Improving_the_Pair_Selection_and_the_Model_Fusion_Steps_of_WACV_2023_paper.html)
  已用离线模拟预测像对完整性并改进像对选择/DSM 融合。
- [Dym 等，ICML 2024](https://proceedings.mlr.press/v235/dym24a.html) 已给连续单值/有限 frame
  canonicalization 的障碍与 weighted frames；重新训练 canonicalizer 不是本项目的新理论。
- [BOP-Distrib](https://arxiv.org/abs/2408.17297) 已把逐图像可见性引起的姿态多解写进真实图像
  benchmark；集合化方向输出本身不足以构成贡献。

TRDC 若最终只剩“元数据模型选更好图”，即与上述工作实质重合，应停止而不是换标题。

### 2. 对 r015 边界是否有异议

没有。C 同意停止 r015，且不同意补 epoch、seed、224 输入、单属性或修正训练 recipe 来续命。
实际 recipe 下 G8 的负向区间限制可描述；G2 仍不精确，不能写零效应。训练与统计偏差也意味着
原合同不能被事后 CPU 重算追认。r015 的结论不外推到真实物理多视角或所有等变模型。

### 3. 最小可独立核实对象、任务与成像量

首次验证原则原应优先 HRSC2016；**本问题需要同一静态目标的独立重复物理观测、RPC/视线方向和
独立任务真值，HRSC2016 不提供这些量，因此不适配。** RarePlanes 又没有可靠的同一飞机跨期身份，
不再用它做此问题。

可行资产分三层：

1. **SpaceNet MVOI 只做最小证伪。** 官方数据为同一 Atlanta 665 km²、27 个 WorldView-2 视角、
   120,000 余建筑足迹，并公布 off-nadir、target azimuth 与 Pan GSD。静态建筑/地理 tile 提供
   同一实体，远强于 RarePlanes 的“同位置飞机”。但它只有一城、一传感器、一次轨道获取，且
   方位、离轴角、GSD、阴影/建筑高度强共线；单独阳性不能支撑跨来源顶刊主张。
2. **[US3D](https://www.grss-ieee.org/community/technical-committees/2019-ieee-grss-data-fusion-contest/) 做外部地点验证。** 官方竞赛材料提供 Jacksonville 与 Omaha 的多日期、多视角
   WorldView-3、RPC、LiDAR 几何和语义真值；公开论文报告两地分别约 26/43 个视角。可一城开发、
   一城冻结验证，但仍然只是同一传感器族的地点外推。
3. **[WHU-TLC](https://gpcv.whu.edu.cn/data/whu_tlc.html) 只作跨传感器几何诊断。** 它有 ZY-3 同时三线阵、精调 RPC 与 LiDAR/GCP DSM，
   但没有与 MVOI/US3D 对齐的独立语义/对象任务，不得用来冒充同任务跨传感器确认。

真正的 TGRS 级跨传感器结论还需要第二个带可比任务标签的传感器来源；若找不到，目标上限应写
JPRS 候选而非 TGRS。

每个实验单元至少要独立绑定：静态 tile/对象身份、任务标签、RPC 或视线向量、target/sun azimuth、
off-nadir、源 GSD、获取时间、辐射/噪声质量和可见支持。部署预测器只能读取首幅观测与获取前可得
元数据，不能读取候选图像的 GT、最终任务损失或 test 调参结果。

### 4. 哪个最小反例足以推翻假说

理论反例是：若每个已标定算子均可逆，或标准校正产生恢复任务相关潜变量的充分统计量，则校正后的
Bayes 风险不依赖方向；若固定信息预算下两观测的任务相关 Fisher 信息和不随夹角变化，则互补方向
也不优于重复方向。此时 raw 网络的方向损失只是有限模型或预处理不足。

经验上以下任一项即关闭 TRDC 顶刊路线：

1. 找不到在 nuisance 共同支持内的真实 `anchor + redundant + complementary` 三联观测；这是资产/
   可识别性失败，不是科学零效应。
2. RPC/几何、GSD/PSF、时间、太阳角、遮挡或绝对单帧质量校正后，相对方向不再提供来源外预测增量。
3. 同一融合器与同一计算预算下，互补第二视角不优于近同方向独立重复视角；说明收益只是多一幅图。
4. 方向模型不优于 nuisance-only、固定最佳角、随机、Qin 元数据像对质量、Gomez 模拟完整性和任务
   NBV 基线。
5. Atlanta 开发得到的增益排序/校准不能迁移到 Jacksonville/Omaha；地点外推失败。
6. 即使有效，最终贡献仍只能表述为已有 active detection/view selection 的遥感复现；新颖性失败。

## 建议的新方法与决定性实验

### 推断对象

对静态单元 `u`、首视角 `i` 和候选第二视角 `j`，固定同一任务模型/融合器 `F`，定义候选的边际收益

`Delta(u,i,j) = loss(F(X_i),Y_u) - loss(F(X_i,X_j),Y_u)`。

再取 nuisance 匹配的近同方向独立观测 `r`，定义方向互补净收益

`C(u,i,j,r) = loss(F(X_i,X_r),Y_u) - loss(F(X_i,X_j),Y_u)`。

论文的主要结局应是 `C` 及其来源外预测误差/排序 regret，而不是角误差、置信度、熵、OBB IoU 或
由 GT_AR 合成的代理风险。

### 方法构成

1. **物理几何表示。** 由 RPC/获取元数据计算首视角与候选视角的地面视线、相对方位、交会角、GSD、
   太阳方向和时间差；从首图估计场景结构轴及其不确定性，不向部署模型输入 GT 方向。
2. **共同支持与 nuisance 残差化。** 先拟合不含相对结构方向的 nuisance-only 模型；只在方位夹角
   与 GSD/离轴/时间/太阳角存在重叠支持的三联观测中估计方向增量。全表 shuffle 不能替代该设计。
3. **边际增益估计器。** 输入首图特征、候选获取元数据和相对方向分布，直接回归 `Delta` 并做
   pairwise ranking；训练标签由开发来源中固定融合器的真实任务损失产生。选择器不与下游任务模型
   联合调参，避免把过拟合称为物理规律。
4. **同成本候选选择。** 每次只选一幅候选第二图；所有策略使用相同像素、相同两视图融合器与推理
   预算。评价选择 regret、真实任务损失改善和增益预测校准。

只有当方向项在标准校正、绝对图像质量和既有像对选择基线之外仍提供稳定的 held-out 增益，才有资格
讨论“任务相关 null-space 互补性”。在此之前，不把该词写成已证明机制或新定理。

### 分阶段生死门

- **L0 资产/识别性门（CPU、outcome-blind）：** 只核验三个数据源的许可、在库状态、真实元数据字段、
  三联观测数量、nuisance 共同支持、地理分区和可计算任务标签。不训练、不读取 test outcome。
- **L1 最小证伪（MVOI）：** 固定一个公开且正常的建筑分割/检测器与简单、相同的两视图融合器，
  穷举开发 tile 的候选二视图任务收益；先检验相对方向是否在 nuisance-only 和现有选择基线之外有
  来源 held-out 增量。失败即停止，不上大模型。
- **L2 方法验证（US3D）：** 只有 L1 通过才训练 TRDC 增益估计器；按地理 tile 和获取事件分层，
  一城开发、一城冻结验证，并用语义 3D/建筑任务的真实损失检验选择 regret 与校准。
- **L3 跨传感器确认：** 只有找到第二传感器、同一推断对象和可比任务真值才执行。WHU-TLC 只能作
  几何诊断，不能单独完成这一步。

## 期刊级别与论文组织

- **现在：** 需要收缩后的 JSTARS 类方向测量/审计稿候选，尚非 ready。
- **只在 MVOI 得到单城正向：** 仍不足以升至顶刊；主动相机配置和 MVOI 选角已有直接工作。
- **MVOI 最小证伪 + US3D 跨城确认，且 TRDC 胜过物理/元数据/任务 NBV 强基线：** JPRS 才成为
  可信投稿目标。主贡献应是新推断对象、真实多视角基准和可迁移增益估计，而不是多一个网络模块。
- **再有同任务跨传感器确认，且能证明/估计任务相关不可逆信息互补：** 才可讨论 TGRS。
- **TPAMI/IJCV：** 目前没有跨视觉领域的理论与数据广度，不列为现实目标。

旧 OrientBench 测量结果应作为动机与评价协议边界，而不是继续充当主方法证据。新论文的主线应从
“OBB 分数没有表达方向风险”改为“在真实成像预算下，何时第二视角提供不可由冗余观测替代的任务
信息，以及这种价值能否在获取前预测”。如果 L0 找不到合格三联支持，应立即停止新路线并收敛现有
测量稿，不再用任务号、模型数量或同类数据集续命。
