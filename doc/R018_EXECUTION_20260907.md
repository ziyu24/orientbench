## 执行内容

1. 核验既有模型与结果行摘要；逐个检查冻结384区域的原始图网格与区域名对应、四视角CRS、
   标签CRS及共同mask。统计900栅格后缩放与直接448栅格化的真实差异，训练/评估分别报告。
   有效空标签保持全背景，保留Polygon/MultiPolygon孔洞；不剔除边界复杂或不利样本。
2. 同一模型对每个评估区域作四个单视角前向，A/B各再做一次90°前向。逆旋转后的完整预测必须
   为448×448；严格禁止一行向全图广播。保存FP32的四个基图和两个对齐旋转图，后续统计可CPU重放。
3. 输出两套配对结果：实际缓存标签是r017实际拟合的评估更正；直接448标签仅作为评估敏感性。
   两套均使用同一预测、有效像素和固定训练权重。第二套不是原训练协议恢复，也不是新确认集。
4. 两套均报告I、ΔA/ΔB、各seed、四单图与四融合、正确TTA、常数基线和前景IoU。
   显式报告G_A=L(TTA_A)−L(A,V)、G_B=L(TTA_B)−L(B,U)，正值表示真实互补优于该TTA。
   不把错误TTA结果或较弱常数基线当作强方法。
5. 每seed先块内切片等权，再seed等权、16块等权；IoU先每seed每块汇总交/并取比例，
   再seed/块等权，不跨seed先池化分母。未定义IoU如实报告。
   沿用PCG64(17017)、20,000次配对块bootstrap、冻结清单首次出现的块顺序。
   I是原主量，其余区间作描述，不挑显著子组或把这轮当新的盲确认。
6. 从新预测重建旧错误TTA，只用于复现误差原因；与原行比较未受影响的损失与旧TTA，
   最大绝对偏差容限1e-5。超出时保留并解释模型/计算漂移，不追认同一评估或反复重跑凑一致。
