1. **改写在数学上成立。**对固定查询 \(q=(X,Y)\)，令 \(T_q(s)\) 为候选场景的最高表面高程，\(V_q(s)\in\{0,1\}^3\) 为该表面点的三视可见性。比较
   \[
   \mathcal C(y),\qquad
   \mathcal C_V(y)=\{s\in\mathcal C(y):V_q(s)=V_q(s^\*)\}.
   \]
   分别计算 \(T_q\) 的精确最小值和最大值即可。三比特最多将候选集分为八组，但某一组仍可能显著收紧高度范围，不能仅因信息粗就判无意义。`000` 也可能排除候选，无须要求它改善或不改善。

2. **必须固定 oracle 的信息预算。**主实验建议每个查询只使用自己的三个布尔值，分别求界。若一次交付全部查询的可见向量，就可能形成空间可见性图，并通过场景耦合提供更多信息；那是另一种 oracle。四类场景的类别标签只能用于汇总，不能交给推断器或用来缩小候选库。

3. **可见性的定义还需写死。**每个候选都检查其自身的最高表面点，不能沿用真场景的高度或投影位置。固定查询应在预定候选高度范围内均落入三幅影像视场；否则“不可见”会混入出界。地面存在、射线相切及遮挡判定的数值容差也须统一。所有真场景使用同一预先固定的候选类，不能逐例按真值裁剪搜索范围。

4. **零遗漏、零空集是实现必需条件，不是额外科学发现。**真场景在类内、噪声满足已知界、枚举与 oracle 正确时，真场景必然保留。违反任一项应判实现或设定无效，不能判 visibility 无价值。区间宽度不增也应作为必查性质。

5. **接受 48 场景、四类各 12、seed1701，以及提出的筛选阈值。**主收缩率建议明确为

   S=1-\frac{\operatorname{mean}W_V}{\operatorname{mean}W_0},
