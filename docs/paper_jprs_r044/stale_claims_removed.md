# Stale and over-broad claims removed

The manuscript package does not carry forward the following claims.

- **A nonlinear geometry selector wins after fixed-size control.** Removed as a positive contribution. The later circularity analysis attributes the dominant reversal to the aspect-ratio-defined estimand component; target-domain GT fitting remains an analysis upper bound, not a deployable method.
- **PSC intrinsic phase confidence is universally or stably anti-calibrated.** Removed. The retained evidence supports only detector/dataset-level score-ranking statements, with DIOR-R, FAIR1M, SODA-A, and DOTA showing different behavior. It does not establish that the PSC angle head is generally anti-calibrated.
- **Q-SetOD provides transferable coverage repair.** Removed. The corrected adjudication terminated this route.
- **OER/OER-D repairs orientation ranking.** Removed. The evaluated matrix contained no positive improvement in the prespecified generalized risk-coverage contrast.
- **SAUR is a successful orientation head or proves that symmetric heads cannot work.** Both claims are removed. The evaluated configuration suffered large detection-accuracy regressions; its implementation also differed from the frozen formula, so the result rejects only that execution and cannot support a class-wide impossibility statement.
- **DOTA is a public-test replication or state-of-the-art comparison.** Removed. DOTA-v1.0 is reported only under the project's local train/val protocol and as a post-outcome audited external replication where applicable.
- **NRC is independent of mAP.** Removed. The manuscript says only that NRC provides an additional reliability view within comparable settings.
- **Human disagreement estimates dataset ground-truth error.** Removed. Independent disagreement is used only as a semantic noise anchor and is never subtracted from detector error.

The tracked pre-annotation tables under `top_journal_v3_reaudit_055/reports/m4_human_annotation_*` that still state `HUMAN_BLOCKED` are superseded for outcome claims by `reports/m4_human_annotation_primary_summary_073.csv` and `reports/m4_human_annotation_analysis_audit.json`.
