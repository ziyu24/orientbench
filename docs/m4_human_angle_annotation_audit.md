- 两名真实标注者在互盲条件下独立完成同一组 600 个 canonical targets；DIOR-R、FAIR1M-v1.0、SODA-A 各 200 个，标注者身份不同，原始文件已持久化。

- 人工 disagreement 不是数据集真实 GT error，不能作为从模型误差中扣除的修正项。corner-jitter 仅为独立的 proxy sensitivity，不称为真实标注方差。
